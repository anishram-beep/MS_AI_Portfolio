# MS AI Portfolio

A curated portfolio of machine learning, computer vision, optimization, NLP, and simulation-focused projects completed during my M.S. in Artificial Intelligence and related coursework.

## About Me
I am an M.S. in Artificial Intelligence student at George Mason University with experience in computer vision, machine learning, signal processing, and optimization-driven systems. My work focuses on building practical ML systems for perception, decision support, and performance optimization.

## Featured Projects

### 1. AI Speaker Optimization
Optimization-driven audio calibration system using Gaussian Processes and Bayesian Optimization to improve frequency response across listening positions.

**Skills:** Bayesian Optimization, Gaussian Processes, Signal Processing, Python  
**Folder:** `AI_SpeakerOptimization`

### 2. Nighttime Computer Vision / Image Restoration
Computer vision projects involving image restoration, multiscale pyramids, and low-light enhancement techniques for robust perception.

**Skills:** OpenCV, Image Processing, Multiscale Methods, Python  
**Folder:** `Comp_Vision_Proj`

### 3. Deep Learning Projects
A collection of deep learning coursework and experiments involving model development, notebooks, reports, and training outputs.

**Skills:** PyTorch, CNNs, Deep Learning, Python  
**Folder:** `DeepLearning_Projects`

### 4. FinBERT Earnings Sentiment & Financial Signal Prediction
End-to-end NLP + financial modeling pipeline combining FinBERT sentiment, text feature extraction, and ensemble models for post-earnings prediction.

**Skills:** NLP, FinBERT, spaCy, Random Forest, Gradient Boosting, Python  
**Folder:** `Earnings Sentiment & Financial Signal Prediction (FinBERT)`

### 5. Responsible AI Multi-Agent Architecture for Autonomous Vehicles
Safety-oriented autonomous vehicle architecture focused on perception confidence monitoring and fail-safe override logic in simulated settings.

**Skills:** AI Safety, Simulation, Multi-Agent Systems, Autonomous Systems  
**Folder:** `RAI_MultiAgentArch_AutonomousCar`

### 6. Truck Delivery Optimization
Software project for package delivery optimization using object-oriented design and route-planning logic.

**Skills:** Algorithms, OOP, Python, Optimization  
**Folder:** `Truck_DeliveryOptimization`
