# Truck Delivery Optimization

## Overview
This project implements a package delivery optimization system using object-oriented design and route-management logic.

## Problem
Efficient delivery scheduling requires coordinating packages, trucks, and routes under practical constraints. The goal was to build a delivery manager that models these entities and supports route execution.

## Approach
I implemented an object-oriented delivery system with classes for packages, trucks, and delivery management. The project focuses on managing package states, truck behavior, and execution flow for a delivery optimization scenario.

## Methods and Tools
- Python
- Object-oriented programming
- Algorithm design
- Route and package management

## Files
- `main.py` — entry point
- `DeliveryManager.py` — delivery coordination logic
- `Package.py` — package representation
- `Truck.py` — truck representation
- `Tester.py` — testing support

## Key Takeaways
- Practiced software design for logistics-style optimization
- Used modular OOP structure to separate delivery responsibilities
- Built a project demonstrating practical algorithmic reasoning beyond pure ML

## How to Use
1. Open `main.py` to see how the program is run
2. Inspect the class files for architecture and logic
3. Use `Tester.py` for validation or experimentation
